1. 프로젝트 개요
바탕화면 위에 작은 아이콘 형태로 항상 떠 있으면서, 클릭 한 번으로 오늘의 일정을 확인하고 관리할 수 있는 개인용 스케줄
러 앱입니다. 일정 관리 외에 심심풀이용 부가 기능으로 메뉴 추천과 숫자 맞추기 미니게임을 제공합니다.
1.1 핵심 목표
다른 창에 가려지지 않는 작은 플로팅 아이콘으로 일정에 즉시 접근한다.
일정 등록·수정·삭제·완료 체크·알림을 간단한 조작으로 처리한다.
가볍게 실행되고, 인터넷 연결 없이 로컬(SQLite)에서 모든 데이터를 관리한다.
미니게임과 메뉴 추천은 확장하기 쉬운 구조(인터페이스 기반)로 만든다.
1.2 범위
구분 내용
포함 플로팅 아이콘, 일정 관리(월간 캘린더·오늘 목록), 알림, 메뉴 추천, 숫자 맞추기 게임, 설정, 로컬 데이터 저
장, 트레이 아이콘, W indows 설치 파일 패키징
제외 (v1.0) 클라우드 동기화, 계정/로그인, 모바일 연동, 외부 캘린더(구글 등) 연동, 다국어(한국어 고정)
1.3 우선순위 표기
필수 = v1.0에 반드시 구현 / 권장 = 시간이 되면 구현 / 선택 = 이후 확장
2. 기술 스택 및 개발 환경
항목 선택 이유
언어 J ava 21 (LTS) 데스크톱 앱 개발에 안정적이며 AI 도구의 코드 생성 품질이

3. 주요 기능 명세
3.1 플로팅 아이콘 (Always on Top)
ID 요구사항 우선순위
F-01 앱 실행 시 바탕화면에 약 64× 64px의 원형(또는 둥근 사각형) 아이콘이 표시된다. 창 테두리·배경은 투
명하고 다른 모든 창 위에 항상 표시된다 ( StageStyle.TRANSPARENT , setAlwaysOnTop(true) ).
필수
F-02 마우스 드래그로 아이콘을 원하는 위치로 이동할 수 있고, 종료 후에도 마지막 위치를 기억한다. 필수
F-03 작업 표시줄에는 아이콘 창이 나타나지 않는다 (숨김 owner 스테이지 사용). 필수
F-04 좌클릭 : 퀵 패널(오늘 일정 미니 목록) 열기/닫기. 더블클릭 : 메인 창 열기. 필수
F-05 우클릭 컨텍스트 메뉴 : 메인 창 열기 / 일정 추가 / 메뉴 추천 / 숫자 맞추기 / 설정 / 종료. 필수
F-06 아이콘 모서리에 오늘 남은 일정 개수 배지를 표시한다. 권장
F-07 화면 가장자리에 가까이 놓으면 자석처럼 붙고(스냅), 마우스를 올리지 않으면 투명도를 낮춘다. 권장
F-08 아이콘 크기(48/64/96px)와 투명도를 설정에서 변경한다. 모니터 해상도·DPI 배율 변경에도 화면 밖으
로 벗어나지 않도록 위치를 보정한다.
권장
F-09 아이콘 클릭 시 퀵 패널이 아이콘 근처(화면 안쪽 방향)에 팝업된다. 필수
3.2 일정 관리
ID 요구사항 우선순위
S-01 일정 등록 : 제목, 날짜, 시작/종료 시간(또는 종일), 메모, 카테고리, 우선순위(높음/보통/낮음), 알림 시
간.
필수
S-02 일정 수정·삭제, 완료 체크박스(완료 시 취소선 처리). 필수
S-03 월간 캘린더 뷰 : 일정이 있는 날짜에 점 표시, 날짜 선택 시 해당 일 목록 표시. 필수
S-04 오늘 일정 목록 뷰 : 시간순 정렬, 미완료/완료 구분, 지난 일정 강조. 필수
S-05 알림 : 지정한 시각(예: 10분 전)에 화면 우측 하단 토스트 팝업과 트레이 알림을 표시한다. 앱이 켜져 있
는 동안 ScheduledExecutorService가 1분 단위로 확인한다.
필수
S-06 반복 일정 : 매일 / 매주(요일 선택) / 매월 / 매년. 권장
S-07 D-Day 표시 : 중요한 일정에 D-Day 표시를 켜면 남은 일수를 계산해 목록과 퀵 패널에 보여준다. 권장
S-08 카테고리(업무·학업·개인·기타)별 색상 구분 및 필터, 제목/메모 검색. 권장
S-09 알림 미루기(5분 / 10분 후 다시 알림). 선택
S-10 일정 데이터 내보내기/가져오기(CSV). 선택

3.3 메뉴 추천 (심심풀이)
ID 요구사항 우선순위
M -01 "추천받기" 버튼을 누르면 슬롯머신처럼 메뉴 이름이 빠르게 바뀌다가 하나로 멈추는 애니메이션(약 1.5
초) 후 결과를 보여준다.
필수
M -02 식사 시간대(아침/점심/저녁/야식)와 분류(한식/중식/일식/양식/분식/기타)를 선택해 해당 조건에서만
추천한다. 기본값은 현재 시각 기준 시간대로 자동 선택.
필수
M -03 기본 메뉴 목록(약 60개)을 내장하고, 사용자가 메뉴를 추가·삭제할 수 있다. 필수
M -04 최근 3일 이내에 추천(또는 선택)한 메뉴는 중복 추천에서 제외한다. 권장
M -05 "다시 뽑기", "이걸로 결정!" 버튼. 결정한 메뉴는 이력에 저장한다. 필수
M -06 즐겨찾기(가중치 2배)와 제외 목록(싫어하는 메뉴) 관리. 권장
M -07 결정한 메뉴를 오늘 일정(예: "12:00 점심 - 김치찌개")으로 바로 등록한다. 선택
3.4 숫자 맞추기 미니게임
ID 요구사항 우선순위
G -01 컴퓨터가 정한 비밀 숫자를 입력값과 비교해 "U P(더 큼)" / "DOW N(더 작음)" 힌트를 준다. 정답을 맞
추거나 기회를 모두 소진하면 종료.
필수
G -02 난이도 : 쉬움(1~ 50, 10회) / 보통(1~ 100, 7회) / 어려움(1~ 1000, 10회). 필수
G -03 입력 이력(예: 50 → U P, 75 → DOW N)을 목록으로 보여주고, 남은 기회를 표시한다. 숫자 범위 밖의 입
력이나 숫자가 아닌 입력은 안내 메시지를 띄우고 기회를 차감하지 않는다.
필수
G -04 난이도별 최소 시도 횟수 기록(최고 기록)을 DB에 저장하고 결과 화면에 표시한다. 권장
G -05 정답/실패 시 간단한 효과(색상 변화, 흔들림 애니메이션)와 "다시 하기" 버튼. 권장
G -06 이후 다른 미니게임(가위바위보, 카드 짝 맞추기 등)을 쉽게 추가할 수 있도록 M iniG am e 인터페이스와
게임 선택 화면을 만든다.
권장
3.5 설정 / 공통
ID 요구사항 우선순위
C-01 W indows 시작 시 자동 실행 on/oﬀ (시작프로그램 폴더 바로가기 또는 레지스트리 Run 키). 권장
C-02 시스템 트레이 아이콘 : 열기 / 아이콘 숨기기·보이기 / 종료. 메인 창을 닫아도 앱은 트레이에서 계속 실

필수
C-03 앱 중복 실행 방지(이미 실행 중이면 기존 인스턴스의 메인 창을 앞으로 가져오고 종료). 권장
C-04 테마 : 라이트 / 다크 (CSS 파일 교체). 선택
C-05 데이터 백업 : DB 파일 복사본 저장 / 복원. 선택

1. 숨김 owner 스테이지(StageStyle.U TILITY, 크기 0, 투명)를 하나 만들고, 아이콘 스테이지의 owner로 지정해 작업 표
시줄 표시를 막는다.
2. 아이콘 스테이지 : initStyle(StageStyle.TRANSPARENT), setAlwaysOnTop(true), Scene 배경 Color.TRANSPARENT .
3. 드래그 : setOnM ousePressed에서 오프셋 저장 → setOnM ouseDragged에서 스테이지 X/Y 갱신. 이동 거리가 5px 미
만이면 "클릭"으로, 이상이면 "드래그"로 구분한다.
4. 드래그 종료 시 위치를 Screen.getScreensForRectangle()으로 현재 모니터 영역 안으로 보정하고 DB(app_setting)에
저장한다.
5. 투명 창의 그림자 효과는 아이콘 크기보다 10~ 15px 큰 투명 여백을 두고 DropShadow 로 처리한다.
6. 마지막으로 Platform .setIm plicitExit(false)로 모든 창이 닫혀도 앱이 종료되지 않게 하고, 종료는 트레이/우클릭 메뉴의
"종료"에서만 수행한다.
6.2 알림 처리
Alarm Service는 앱 시작 시 오늘 이후 일정 중 알림이 설정된 것을 메모리에 적재하고 1분마다 현재 시각과 비교한다.
일정이 추가/수정/삭제되면 즉시 알림 목록을 다시 불러온다.
한 번 울린 알림은 재알림되지 않도록 ﬁred 집합(일정 ID + 발생일)으로 관리한다. U I 갱신은 반드시
Platform .runLater()로 수행한다.
6.3 반복 일정 전개 규칙
반복 일정은 DB에 원본 1건만 저장하고, 월간 조회 시 조회 기간 내 발생일을 계산해 가상 인스턴스로 만든다.
반복 일정의 완료 체크는 날짜별로 따로 기록할 수 있도록 schedule_done(schedule_id, date) 보조 테이블을 추가한다
(권장 단계에서 구현).
매월 31일 반복은 해당 월에 31일이 없으면 말일로 보정한다.
6.4 메뉴 추천 알고리즘
1. 후보 = (선택한 시간대·분류에 해당) − (제외 목록) − (최근 3일 이력).
2. 후보가 비면 이력 제외 조건을 풀어 다시 계산하고, 그래도 비면 "조건에 맞는 메뉴가 없어요" 안내를 표시한다.
3. 가중 랜덤 : 일반 메뉴 가중치 1, 즐겨찾기 가중치 2로 하나를 뽑는다.
4. 애니메이션은 Tim eline으로 후보 이름을 50m s 간격으로 바꾸다가 속도를 점점 늦춰 최종 결과에서 멈춘다. 결과는 애
니메이션 시작 전에 이미 결정해 둔다.
6.5 숫자 맞추기 규칙
