# MySchedule · 나의 하루

Windows 10/11용 개인 스케줄러입니다. 파란 플로팅 아이콘에서 오늘의 일정을 열고, 캘린더·알림·메뉴 추천·숫자 맞추기를 사용할 수 있습니다. 인터넷 연결이나 계정이 필요 없으며 모든 데이터는 내 PC에 저장됩니다.

## 바로 실행
설치해서 사용하려면 **`dist\MySchedule-1.0.0.exe`** 를 실행하세요. 현재 Windows 사용자에게 설치하고 시작 메뉴와 바탕화면 바로 가기를 만듭니다. MSI 형식도 제공합니다. 다른 PC로 옮길 때는 `MySchedule-1.0.0-portable.zip` 전체를 풀어서 사용하세요.

첫 실행에는 빈 캘린더가 나옵니다. 테스트 일정은 실제 데이터에 넣지 않았습니다.

## 사용하는 방법

| 기능 | 사용 방법 |
| --- | --- |
| 플로팅 아이콘 | 한 번 클릭하면 오늘의 퀵 패널, 더블클릭하면 메인 창을 엽니다. 드래그해 옮길 수 있습니다. |
| 아이콘 우클릭 | 일정 추가, 메뉴 추천, 게임, 설정, 종료로 이동합니다. |
| 캘린더 | 날짜를 선택하면 오른쪽에 일정이 나옵니다. 날짜 더블클릭 또는 새 일정 버튼으로 등록합니다. |
| 오늘의 일정 | 오늘의 전체·남은·완료 수와 시간순 일정을 확인합니다. |
| 새 일정 | 제목, 날짜, 시간/종일, 메모, 카테고리, 우선순위, 알림, 반복, D-Day를 설정합니다. `Ctrl+N`도 가능합니다. |
| 수정·삭제·완료 | 일정 카드의 버튼 또는 체크박스를 사용합니다. 완료한 제목에는 취소선이 표시됩니다. |
| 메뉴 추천 | 시간대·분류 선택 → 추천받기 → 이걸로 결정. 메뉴 관리에서 추가·수정·삭제·즐겨찾기·제외를 설정합니다. |
| 숫자 맞추기 | 난이도를 선택하고 숫자를 입력합니다. UP은 더 큰 숫자, DOWN은 더 작은 숫자입니다. |
| 설정 | 라이트/다크, 아이콘 크기·불투명도, 자동 실행, 알림 미리 보기, 데이터 백업을 설정합니다. |

**창의 X는 메인 창만 닫습니다.** 일정 알림과 플로팅 아이콘은 계속 실행됩니다. 완전히 종료하려면 아이콘 우클릭 또는 Windows 트레이의 **종료**를 누르세요. 이미 실행 중인 앱을 다시 실행하면 기존 창을 앞으로 가져옵니다.

## 정해 둔 동작

- 반복 일정 수정·삭제는 **반복 전체**에 적용합니다. 완료는 날짜별로 따로 기록합니다. 특정 하루만 수정하거나 삭제하는 기능은 이번 버전에 없습니다.
- 매월 31일은 짧은 달의 말일로, 2월 29일의 매년 반복은 평년 2월 28일로 보정합니다. 반복 종료일은 포함합니다.
- 날짜를 넘는 시간 일정은 날짜별로 나누어 등록합니다.
- 종일 알림은 **오전 9시** 기준이며, 지정한 분 수만큼 앞당겨 알립니다.
- 알림 확인 주기는 1분이므로 설정 시각에서 최대 약 1분 늦게 보일 수 있습니다. 앱이 실행 중이어야 알림이 옵니다.
- 절전·재실행 후 놓친 알림은 최근 **24시간** 이내만 보여 줍니다. 알림 기록과 5분/10분 미루기는 재실행 후에도 유지됩니다.
- 일정 내용을 수정하면 새 알림 버전으로 계산합니다. 수정한 알림 시간이 이미 지난 경우 24시간 범위 안에서 다시 알릴 수 있습니다.
- 메뉴 기본 데이터는 60개입니다. **결정한 메뉴**만 최근 3일 동안 추천에서 제외합니다. 후보가 없으면 최근 이력 제한만 풀고, 제외한 메뉴는 계속 제외합니다. 즐겨찾기는 일반 메뉴의 2배 가중치입니다.
- 메뉴를 오늘 일정에 담으면 제목과 식사 시간(아침 08시, 점심 12시, 저녁 18시, 야식 22시)이 채워진 편집기를 엽니다. 저장을 눌러야 일정이 등록됩니다.
- 캘린더 검색·카테고리 필터는 표시 중인 캘린더 범위, 오늘 화면에서는 오늘 일정에 적용됩니다.
- 자동 실행은 기본으로 꺼져 있습니다. 배포용 `MySchedule.exe`에서 켤 수 있습니다. 켜 둔 실행 폴더를 옮기면 새 위치에서 껐다가 다시 켜 주세요.

## 데이터와 백업

기본 위치는 `%APPDATA%\PersonalScheduler\scheduler.db`입니다. 설치 폴더와 분리되어 있어 앱을 업데이트해도 유지됩니다. 오류 기록은 같은 폴더의 `app.log`에 남습니다.

설정의 **데이터베이스 백업**은 실행 중에도 일관된 SQLite 복사본을 만듭니다.

복원할 때는 다음 순서로 진행하세요.

1. 아이콘 또는 트레이에서 앱을 **완전히 종료**합니다.
2. 기존 `%APPDATA%\PersonalScheduler` 폴더를 다른 위치에 복사해 보관합니다.
3. 백업 파일을 해당 폴더에 `scheduler.db`라는 이름으로 복사합니다.
4. 비정상 종료 후 남아 있는 `scheduler.db-wal`, `scheduler.db-shm`이 있다면 기존 DB와 함께 별도 보관해 원래 폴더에서 제거합니다. 다른 DB의 WAL을 복원한 DB와 섞지 마세요.
5. 앱을 다시 실행합니다.

CSV 가져오기/내보내기는 이번 버전에 포함하지 않았습니다. DB 백업에는 일정·완료·알림 상태·메뉴·게임 기록·설정이 함께 포함됩니다.

## 개발과 빌드

프로젝트에는 Java 21, Maven Wrapper, WiX 3을 사용할 수 있는 스크립트가 있습니다. 기존 시스템 Java 17이나 PATH를 바꾸지 않았습니다.

```powershell
.\mvnw.cmd test
.\mvnw.cmd javafx:run
.\scripts\build.cmd
.\scripts\package.cmd
```

처음 다른 개발 PC로 소스를 옮겼다면 `powershell -ExecutionPolicy Bypass -File scripts\Setup.ps1 -IncludeWix`로 프로젝트 전용 도구를 준비합니다. 빌드 도구와 의존성의 최초 다운로드에만 인터넷이 필요합니다.

- UI: JavaFX 21, FXML, 라이트/다크 CSS
- 저장: SQLite JDBC, 짧은 연결·즉시 커밋·WAL
- 구조: `model`, `repository`, `service`, `ui`, `menu`, `game`
- 테스트: JUnit 5
- 배포: jpackage, 런타임 포함 Windows 실행 폴더·ZIP·EXE·MSI

자세한 도구 버전과 라이선스는 [docs/toolchain.md](docs/toolchain.md), 검증 결과는 [docs/TESTING.md](docs/TESTING.md)를 참고하세요.
